# 3D models

| Model | Variants |
|---|---|
| ESP32-C6 + RS-485 sniffer enclosure | [free-standing](esp32c6-rs485-enclosure/freestanding/README.md) · [DIN rail](esp32c6-rs485-enclosure/din-rail/README.md) · [source](esp32c6-rs485-enclosure/source/) |

Models are parametric OpenSCAD. To render them, install `openscad@snapshot`; the stable
cask is disabled in Homebrew.

```bash
brew install --cask openscad@snapshot
```
